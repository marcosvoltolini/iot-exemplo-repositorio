## Enunciado: Vamos ligar o LED!

Desafio Extra!
Colocar mais um led e desenvolver uma
lógica onde aperta 1 vez o botão ligue o LED
1, apertar uma segunda vez ligue o LED 2,
apertar uma terceira vez desligue

## Materiais necessários

| Qtd | Componente |
|-----|------------|
| 1 | Placa Arduino UNO |
| 1 | Cabo USB |
| 1 | Protoboard |
| 1 | Resistor de 200 Ω ou 220 Ω |
| 1 | Resistor de 10 kΩ |
| 1 | Botão tipo push button |
| 1 | LED vermelho difuso de 5 mm |
| — | Fios de jumper macho-macho |
